## 交付接口

**Consumes**：[testing/harness](../testing/harness/README.md) 下的脚本模板；官方 pi SDK（`createAgentSession`、`SessionManager.open`、`ModelRuntime.registerProvider`）；现网 `/v1/models` 与 `/metrics`。

**Produces**：
- `eval/local/cases.json`：12 场景（W01–W03 标 `runner:"vitest"`，不在这里跑），每条 `{id, kind, fixture, taskFile, windowProfile, arms, reps, seed, oracle, protectedPaths}`。
- `pi-config/w262k/models.json`：provider `work`、`baseUrl http://127.0.0.1:18343/v1`（容器内由 E02 改为 `host.docker.internal`）、`contextWindow 262144`、`maxTokens 8192`、`reasoning true`、`compat.supportsReasoningEffort true`。`w64k` 仅 `contextWindow 65536`。
- `run-episode.mjs --case L01 --arm balanced --window w262k --rep 1 --out <dir> [--seed <session.jsonl>]`：复制夹具到临时工作区并 `git init` 基线；按 arm 准备 agentDir（native：无 extensions；observe/balanced：`settings.json.extensions=[dist/extension.js]` + `pctx.json` profile）；`metrics-snap` 前后；SDK 创建会话（seed 时 `SessionManager.open(seedCopy)`）；顺序 `prompt` TASK.md 各段；订阅事件写 `events.jsonl`（`message_end` usage、`tool_execution_start/end`、`session_compact`）；结束后调用 `/pctx status` 等价 API 写 `status.json`；输出 `EpisodeResult`（oracle 字段留给 E02 填）。
- `record-seed.mjs --out eval/local/seeds/<name>.jsonl`：在 `w64k` native 下于一个会话内连续完成 L04、L05、L06 三题（同一工作区不同子目录），中途一步让模型 `bash cat .probe/nonce.txt`（控制器生成随机 32 hex 并在录完后删除文件与 shell 历史），产出 ≥ 40k token 的真实历史 JSONL 与 `seed-meta.json{nonce_sha256, tokens, entries}`。nonce 明文只写入 `eval/local/seeds/<name>.secret`（`.gitignore`），供 E02 判题容器读取。
- `parse-session.mjs <session.jsonl>`：产出 `requests[]`（每 assistant 的 `usage.input/cacheRead/output/totalTokens/stopReason`）、`toolCalls[]`、`compactions`、`historyReads/historySearches`（按 toolName=pctx_history 与 arguments.action）。
- `test/unit/local-cases.test.ts`：cases.json 与 scenarios.json 一致（id、arms、reps、window）；每个 fixture 目录存在 `TASK.md` 或 `initial/`；`protectedPaths` 非空；`parse-session` 对一份仓库内的样例 JSONL（`test/fixtures` 已有或本任务添加最小样例）算出确定值。

## 第一条行为 RED

```ts
import { readFileSync } from "node:fs";
import { join } from "node:path";
import { expect, it } from "vitest";
import { parseSession } from "../../eval/local/parse-session.mjs";

const repo = join(import.meta.dirname, "../..");

it("cases.json mirrors the frozen scenario matrix", () => {
  const cases = JSON.parse(readFileSync(join(repo, "eval/local/cases.json"), "utf8"));
  const scen = JSON.parse(readFileSync(join(repo, "docs/pi-context-native-first-audit-v6.0.0/testing/scenarios.json"), "utf8"));
  expect(cases.cases.map((c: { id: string }) => c.id).sort()).toEqual(scen.cases.map((c: { id: string }) => c.id).sort());
  for (const c of scen.cases) {
    const local = cases.cases.find((x: { id: string }) => x.id === c.id);
    expect(local.arms).toEqual(c.arms);
    expect(local.reps).toBe(c.reps);
    expect(local.windowProfile).toBe(c.windowProfile);
  }
});

it("parse-session counts requests, cacheRead and history reads from a Pi JSONL", () => {
  const parsed = parseSession(join(repo, "test/fixtures/local-eval/sample-session.jsonl"));
  expect(parsed.requests.length).toBe(3);
  expect(parsed.requests[1].cacheRead).toBe(86);
  expect(parsed.historyReads).toBe(1);
  expect(parsed.compactions).toBe(0);
});
```

## 实施顺序

1. 复制夹具到 `eval/local/fixtures/L01..L06`；写 `cases.json`（照 [scenarios](../testing/scenarios.json)）。
2. 写 `pi-config/*`，`ensure-tunnel.sh`（幂等，`ssh -f -N -L 127.0.0.1:18343:127.0.0.1:18343 hhtele@192.168.10.29`，成功后 `curl /v1/models` 校验 `data[0].id` 与 `n_ctx`）、`metrics-snap.sh`（抓 `ninfer:requests_total`、`ninfer:prefix_cache_hit_tokens_total`、`llamacpp:prompt_tokens_total`、`ninfer:continuation_stable_prefix_restores_total`）。
3. `run-episode.mjs` 按 [harness 模板](../testing/harness/run-episode.mjs) 落地；先用 `--arm native --case L04 --window w262k` 跑通一个真实 episode（这是本任务唯一一次消耗 4090 的运行，记录墙钟与 `requests[]`）。
4. `record-seed.mjs` 录制 `seeds/java-three-nonce.jsonl`；`parse-session.mjs`。
5. `cases/H01/TASK.md`、`cases/H02/TASK.md` 照 [harness/cases](../testing/harness/cases/H01/TASK.md) 落地。
6. `eval/local/README.md`：一页说明（隧道、窗口 profile、arm、输出目录、不要在 4090 上改任何东西）。

## 必测负例及边界

- 隧道不通 → `run-episode` 立即 `blocked`（不启动 Pi，不写 result 以外文件）。
- `/v1/models` 的 `n_ctx != 262144` 或 `data[0].id` 不等于 `openclaw/Qwen3.8-27B-WORK` → `blocked`（现网被切回 llama.cpp WORK 时不能混入）。
- arm=native 时 agentDir 里不得有 extensions；observe/balanced 时 `status.json.resolvedProfile` 必须等于 arm，否则 `blocked`。
- seed JSONL 复制到临时目录再打开，原文件 sha 不变。
- 单 episode 墙钟上限 900 s、模型调用上限 40、工具调用上限 80；超限 `timeout` 并保留已写事件。
- `events.jsonl` 不含工具结果正文（只有长度与 hash）。
