## 第一条行为 RED

```ts
import { existsSync } from "node:fs";
import { join } from "node:path";
import { expect, it } from "vitest";
import register from "../../src/extension.js";

const repo = join(import.meta.dirname, "../..");

it("balanced context hook never rewrites the trailing user message", async () => {
  const handlers = new Map<string, (event: unknown, ctx: unknown) => unknown>();
  const pi = { on: (name: string, fn: (e: unknown, c: unknown) => unknown) => handlers.set(name, fn), registerTool() {}, registerCommand() {} };
  register(pi as never);
  const messages = [
    { role: "user", content: [{ type: "text", text: "first" }] },
    { role: "assistant", content: [{ type: "text", text: "ok" }], stopReason: "stop", usage: { input: 1, output: 1, totalTokens: 2 } },
    { role: "user", content: [{ type: "text", text: "second" }] },
  ];
  const ctx = { cwd: repo, sessionManager: { getEntries: () => [], getLeafId: () => null }, getContextUsage: () => ({ tokens: 10, contextWindow: 1000, percent: 1 }), model: { id: "m", contextWindow: 1000 } };
  const out = await handlers.get("context")?.({ type: "context", messages }, ctx);
  expect(messages[2]).toEqual({ role: "user", content: [{ type: "text", text: "second" }] });
  expect(out === undefined || (out as { messages?: unknown[] }).messages?.[2]).toBeTruthy();
  expect(handlers.has("session_before_compact")).toBe(false);
});

it("checkpoint modules are gone", () => {
  expect(existsSync(join(repo, "src/checkpoint"))).toBe(false);
  expect(existsSync(join(repo, "src/projection/exposure.ts"))).toBe(false);
});
```

预期：当前 balanced 在有 capsule 时把胶囊拼进最后一条 user，且 adapter 注册 `session_before_compact`；`src/checkpoint` 存在 → 断言失败。

## 实施顺序

1. `git rm -r src/checkpoint src/projection/exposure.ts src/projection/cache.ts` 与列出的五个旧测试文件。
2. `src/contracts.ts` 删类型；`pnpm typecheck` 用编译错误驱动清理 `src/plugin.ts`、`src/pi/adapter.ts`、`src/commands.ts`、`src/config.ts`、`src/testing.ts` 中的所有引用。
3. `src/plugin.ts`：`confirmAttempt/noteNativeCompact/applyContext` 中的 ledger、generation、capsule 路径全部删除；`noteNativeCompact` 只保留"清空 plan + 计数"（C03 使用）。
4. `src/pi/adapter.ts`：删除 `session_before_compact`；`context` 暂时透传。
5. `src/commands.ts`：删 pin/capsule 命令与其帮助文本。
6. 全量 `pnpm exec vitest run --config vitest.config.ts`，剩余引用 capsule/ledger 的测试按"删测试"处理仅限本任务列表；其他测试若失败，说明有隐藏依赖，先修实现再继续。

## 必测负例及边界

- `rg -n "capsule|ledger|generation|semantic|staging|pin" src/` 只剩注释或与折叠无关的词（如 `pinned` 不允许出现）。
- `pnpm build` 后 `dist/extension.js` 大小明显下降并可被官方 loader 加载（`test/host/stock-loader.test.ts` 仍绿）。
- `/pctx pin` 返回未知命令提示，不是 crash。
- `experimental-semantic` profile 值 → CONFIG_ERROR。
