# C03 · 阈值触发的冻结折叠：plan、render、失效与遥测

**目标**：balanced 在 `ctx.getContextUsage().percent ≥ triggerPercent` 时一次建 plan，把已暴露、非保护的旧工具结果文本替换为确定性 stub，之后每次请求逐字节复用；compaction/tree/model/session 变化失效；每次请求记录 usage 与折叠事件；`/pctx status` 可见。F11、F12 关闭。

**依赖**：C02、B03。
**先读**：[折叠算法](../design/02-fold-algorithm.md) 全文、[合同](../design/01-contracts.md) §4/§5、[本地栈事实](../audit/07-local-stack.md)、现有 `src/projection/planner.ts`、`src/projection/render.ts`。

## 交付接口

**Consumes**：C02 `exposedEntryIds/collectBatches/protectSet`；B01 `refForField`；`ctx.getContextUsage()`、`ctx.model.id`；官方 `message_start`、`message_update`、`message_end`、`session_compact`、`session_tree`、`model_select`、`session_start`。

**Produces**：
- `shouldFold(usage, plan, cfg)`：`usage.percent != null && percent ≥ trigger && plan == null`；有 plan 且 `percent ≥ trigger` 且 plan 建立后又增长 ≥ `minRemovedTokens` 才允许**追加**。
- `planFold(input): FoldPlan | null`（纯函数，见算法 §4）；`previous` 非空时返回的 `replacements` 是超集，旧条目对象引用相同。
- `stubFor(...)`：算法 §stub 形式；`head` 取第一非空行截到 `stubHeadChars`；无换行则取前 `stubHeadChars` 字符。
- `renderFold(messages, plan, mapping)`：算法 §5；`applied=0` 返回同一数组引用。
- `src/plugin.ts` `applyContext(state, messages, ctx)`：算法 §1 数据流；`planStillValid` 四项比较。
- `src/telemetry/usage.ts`：`recordRequest(state, RequestRecord)`（`ttftMs` 由 `message_start` 与同一 assistant 消息的首个 `message_update` 时间差得到，未观察到则 null）、`recordFold(state, FoldEvent)`（`firstChangedIndex` 与 `invalidatedTokensEstimate` 由 planFold 一并返回：折叠前从最旧被替换消息到末尾的估算 token，是本次折叠的 cache 代价）；`telemetry.jsonl=true` 追加写 `~/.pi/agent/pctx/telemetry/<sessionId>.jsonl`，超过 `maxLogBytes` 轮转为 `.1`。
- `src/telemetry/metrics.ts`：`statusView(state, ctx): StatusView` 填齐 `activePlan/folds/nativeCompactions/historyReads/historySearches/lastRequests(5)`。
- `/pctx status` 打印 StatusView；`/pctx status --json`、每次 `agent_end` 与 `session_shutdown` 把同一 StatusView 覆盖写到 `<agentDir>/pctx-status.json`（E 阶段运行器据此断言 arm 身份与机制计数）；`/pctx fold` 手动触发一次（调试用，同样走 planFold，不绕过 minRemovedTokens）。

## 第一条行为 RED

```ts
import { expect, it } from "vitest";
import { planFold, shouldFold } from "../../src/projection/planner.js";
import { renderFold } from "../../src/projection/render.js";
import { collectBatches, protectSet } from "../../src/projection/batches.js";
import { exposedEntryIds } from "../../src/projection/exposed.js";
import { DEFAULT_CONFIG } from "../../src/config.js";
import type { NativeEntry, Scope } from "../../src/contracts.js";

const ok = { input: 10, output: 5, cacheRead: 0, cacheWrite: 0, totalTokens: 15 };
const big = "x".repeat(6000);
const a = (id: string, p: string | null, c: string): NativeEntry => ({ id, parentId: p, type: "message", message: { role: "assistant", stopReason: "toolUse", usage: ok, content: [{ type: "toolCall", id: c, name: "read", arguments: {} }] } });
const r = (id: string, p: string, c: string): NativeEntry => ({ id, parentId: p, type: "message", message: { role: "toolResult", toolCallId: c, toolName: "read", isError: false, content: [{ type: "text", text: `${id}\n${big}` }] } });
const entries: NativeEntry[] = [];
let parent: string | null = null;
for (let i = 1; i <= 8; i++) { entries.push(a(`a${i}`, parent, `c${i}`), r(`r${i}`, `a${i}`, `c${i}`)); parent = `r${i}`; }
entries.push({ id: "a9", parentId: parent, type: "message", message: { role: "assistant", stopReason: "stop", usage: ok, content: [{ type: "text", text: "done" }] } });
const scope: Scope = { workspaceId: "w", sessionId: "s", leafId: "a9", visibleEntryIds: new Set(entries.map((e) => e.id)) };
const cfg = { ...DEFAULT_CONFIG, profile: "balanced" as const };

it("folds oldest exposed results above trigger, freezes them, and leaves the protected tail raw", () => {
  const usage = { tokens: 6500, contextWindow: 10000, percent: 65 };
  expect(shouldFold(usage, null, cfg.fold)).toBe(true);
  const batches = collectBatches(entries);
  const plan = planFold({ scope, entries, batches, exposed: exposedEntryIds(entries), usage, previous: null, modelId: "m", cfg, configHash: "h" });
  expect(plan).not.toBeNull();
  const keys = [...plan!.replacements.keys()];
  expect(keys).toContain("r1:0");
  expect(keys).not.toContain("r8:0");                      // within protectRecentBatches=4
  const messages = entries.filter((e) => e.type === "message").map((e) => structuredClone(e.message));
  const mapping = new Map(messages.map((m, i) => [i, { entryId: entries[i].id }]));
  const out = renderFold(messages as never, plan!, mapping);
  expect(out.applied).toBe(keys.length);
  const stub = (out.messages[1] as { content: { text: string }[] }).content[0].text;
  expect(stub).toMatch(/pctx folded tool result/);
  expect(stub).toMatch(/pctx:6:/);
  const again = renderFold(entries.filter((e) => e.type === "message").map((e) => structuredClone(e.message)) as never, plan!, mapping);
  expect((again.messages[1] as { content: { text: string }[] }).content[0].text).toBe(stub);   // byte-stable
  expect(shouldFold({ tokens: 6600, contextWindow: 10000, percent: 66 }, plan, cfg.fold)).toBe(false); // no re-plan on small growth
});
```

1. `src/contracts.ts`：`FoldPlan/Replacement/ContextUsageLike/RequestRecord/FoldEvent/StatusView`。

5. `src/plugin.ts` `applyContext`：算法 §1；`planStillValid`；balanced 且 `applied=0` 时返回 `undefined`。
6. `src/pi/adapter.ts`：`session_compact/session_tree/model_select/session_start` → `state.plan=null`；`message_end` → `recordRequest`（含当时 `planId/replacementsApplied/contextPercentBefore`）。
7. `src/telemetry/usage.ts` 与 `metrics.ts`；`src/commands.ts` status/fold。
8. `src/config.ts`：`fold` 校验（trigger<85、target<trigger、K≥1、minRemoved≥0）。

## 必测负例及边界

- `usage.percent=null`（压缩后首请求）→ 不建 plan，不 crash。
- 候选总节省 < `minRemovedTokens` → `planFold` 返回 `previous`（可能是 null），无 FoldEvent。
- 折叠后再涨 1% → 不重规划；涨到 `plan.usagePercentAtPlan + minRemovedTokens/window` 以上且 ≥ trigger → 追加，旧条目 stub 字节不变。
- `session_compact` 后 `plan=null`；`compactionBoundary` 变化 → `planStillValid=false`。
- `model_select` 改 `modelId` → plan 失效。
- 同一 toolCallId 在 messages 出现两次 → 该消息不折叠。
- 其他扩展改了某 toolResult 文本（hash 不匹配）→ 该块保持原样，其他块仍折叠。
- 正文 < `minFoldableBytes` 或 stub 不比原文短 → 不折叠。
- `isError=true`、image block、未暴露的最后一批 → 永不出现在 replacements。
- `telemetry.jsonl` 文件里 `rg -c "x{100}"` 为 0（不含正文）。
