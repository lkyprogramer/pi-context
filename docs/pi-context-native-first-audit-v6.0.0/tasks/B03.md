# B03 · 预算内逐字回读与真实图片返回

**目标**：`pctx_history read` 在字节与 token 预算内返回原文，UTF-8 边界向后退不越界；预算与当前上下文剩余量挂钩；图片校验后作为真实 image block 返回。F09 关闭。

**依赖**：B01、B02。
**先读**：[合同](../design/01-contracts.md) §3、[findings F09](../audit/03-findings.md)、现有 `src/history/read.ts`、`src/projection/budget.ts`、`reference/utf8_reference.py`。

## 交付接口

**Consumes**：B01 `decodeRef/refForField`、B02 `Scope`；`ctx.getContextUsage()`（`tokens/contextWindow/percent`）、`ctx.model.contextWindow`。

**Produces**：
- `utf8Prefix(text, maxBytes)`：返回 ≤ maxBytes 且在码点边界的前缀；`maxBytes` 落在代理对/多字节中间时向后退。
- `readHistory(req)`：分页 cursor `{ref, byteOffset}`；每页 `bytes ≤ min(config.readMaxBytes, budget.maxBytes)` 且 `estimateTokens(page) ≤ budget.maxTokens`；返回 `{ page, byteOffset, nextByteOffset|null, totalBytes, sourceHash, verified:true }`。
- `ReadBudget` 计算：`maxTokens = min(config.history.readMaxTokens, caller.maxTokens, floor((contextWindow - usage.tokens) * 0.25))`，`usage.tokens` 为 null 时用 `character-estimate` 并把 `estimateKind` 写入 details；剩余安全量 < 512 token → `INSUFFICIENT_CONTEXT`，不返回半页。
- `formatHistoryResult`：`content = [{type:"text", text: metadataLine}, {type:"text", text: page}]`，图片 ref → `content = [{type:"text", text: metadataLine}, {type:"image", mimeType, data}]`；`details` 保存结构化元数据。图片 hash 不匹配 → `STALE_REF`；图片超过 `readMaxBytes` → `INSUFFICIENT_CONTEXT`，不做静默截断。

## 第一条行为 RED

```ts
import { expect, it } from "vitest";
import { utf8Prefix, readHistory } from "../../src/history/read.js";
import { refForField, encodeRef } from "../../src/history/refs.js";
import type { NativeEntry, Scope } from "../../src/contracts.js";

it("utf8Prefix never splits a code point", () => {
  expect(utf8Prefix("aΩ🙂b", 2)).toBe("a");        // Ω needs 2 bytes, only 1 left
  expect(utf8Prefix("aΩ🙂b", 3)).toBe("aΩ");
  expect(utf8Prefix("aΩ🙂b", 6)).toBe("aΩ");       // 🙂 needs 4 bytes
  expect(utf8Prefix("aΩ🙂b", 7)).toBe("aΩ🙂");
});

it("pages a long block verbatim within bytes and token budget", () => {
  const text = "Ω🙂".repeat(3000);                    // 18000 bytes, 6000 chars
  const entry: NativeEntry = { id: "r", parentId: null, type: "message",
    message: { role: "toolResult", toolCallId: "c", toolName: "read", isError: false, content: [{ type: "text", text }] } };
  const scope: Scope = { workspaceId: "w", sessionId: "s", leafId: "r", visibleEntryIds: new Set(["r"]) };
  const ref = refForField(scope, entry, 0);
  if ("code" in ref) throw new Error(ref.code);
  const p1 = readHistory({ scope, ref: encodeRef(ref), budget: { maxTokens: 1000, maxBytes: 7000, estimateKind: "character-estimate" }, getEntry: () => entry });
  expect(p1.ok && Buffer.byteLength(p1.page, "utf8") <= 7000).toBe(true);
  expect(p1.ok && p1.page.length % 2).toBe(0);         // whole Ω🙂 pairs only
  const p2 = readHistory({ scope, ref: encodeRef(ref), cursor: p1.ok ? p1.nextCursor! : undefined, budget: { maxTokens: 1000, maxBytes: 7000, estimateKind: "character-estimate" }, getEntry: () => entry });
  expect(p2.ok && (p1.ok ? p1.page : "") + p2.page).toBe(text.slice(0, (p1.ok ? p1.page.length : 0) + (p2.ok ? p2.page.length : 0)));
});
```

预期：现有 `read.ts` 按字符切或未把 token 预算与字节预算同时钳住 → 字节或边界断言失败。

## 实施顺序

1. `utf8Prefix` 与字节偏移 cursor（`byteOffset` 是 UTF-8 字节偏移，`Buffer.subarray` 后再退边界）。
2. `ReadBudget` 组装放在 `src/projection/budget.ts`（`readBudgetFor(config, callerMax, usage)`），删除只 clamp 不用结果的旧调用。
3. `readHistory` 逐页校验 `sourceHash`（整块 hash 与 ref 比对一次，页不再单独 hash）。
4. `formatHistoryResult` 分离 metadata/正文/图片；`pctx_history` 工具 schema 增加 `maxTokens` 可选参数。
5. `test/host/history-image.test.ts`：官方 `SessionManager.appendMessage` 写入含 PNG 的 toolResult（用 `reference/` 或仓库 `one-pixel.png`），通过 `createAgentSession` 加载插件后调用 `pctx_history read`，断言返回块 `type==="image"` 且 `data` 与源相同。

## 必测负例及边界

- `maxBytes` 落在 4 字节表情中间：返回不含该字符，`nextCursor` 指向其起点。
- `budget.maxTokens=100` 而正文 8000 token：分 ≥ 80 页，串联等于原文。
- 剩余安全量 < 512 token → `INSUFFICIENT_CONTEXT`，不返回半页。
- 篡改 ref 的 `sourceHash` → `STALE_REF`。
- 图片 `data` 与 hash 不匹配 → `STALE_REF`；图片 > `readMaxBytes` → `INSUFFICIENT_CONTEXT`。
- `cursor.byteOffset` 超过 `totalBytes` → `CURSOR_MISMATCH`。
