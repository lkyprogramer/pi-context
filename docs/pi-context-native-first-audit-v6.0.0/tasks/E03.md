## 交付接口

**Consumes**：E01 `run-episode.mjs`（含 E02 容器）；`cases.json`；`metrics-snap.sh`；`parse-session.mjs`。

**Produces**：
- `eval/local/arm-contract.mjs`：`assertArm(manifest, statusJson, agentDir)`：native → agentDir 无 extensions 且 `status.json` 不存在；observe/balanced → `status.resolvedProfile===arm`、`configHash` 等于 run 冻结值、`hostVersion==="0.85.1"`；失败 → episode `blocked`，写入 `episodes.jsonl` 但不进统计。
- `eval/local/run-matrix.mjs --out artifacts/local-eval/<runId> [--only L01,H01] [--dry]`：冻结 `manifest.json`（git HEAD/tree、dirty 标记、`dist/extension.js` sha256、tarball sha256、镜像 digest、`/v1/models` 回读、cases、arms、reps、预算、随机化后的顺序）；顺序按 case 内 arm 交替（AB/BA 轮换）；每 episode 前 `ensure-tunnel`、`/v1/models` 校验、metrics-snap；调用 `run-episode`；追加 `episodes.jsonl`、`requests.jsonl`；预算（runbook）用尽即停。
- `eval/local/report.mjs <runDir>`：按 case×arm 汇总 `EpisodeResult`：oracle 通过数/总数、`Σinput/ΣcacheRead/Σoutput`（缺 usage 的请求计入 `unknownUsage` 而非 0）、`cacheRead/input` 比、`Σuncached = Σinput − ΣcacheRead`、TTFT p50（来自 `requests[].ttftMs`）、墙钟 p50、wrong-action 数（`protectedIntact=false` 或 `outsideEditable>0` 的 episode 数）、`folds/replacements/nativeCompactions/historyReads/verifiedReads`、每次折叠的 `savedTokensEstimate/invalidatedTokensEstimate`（`removed/invalidated`）、engine `prefixHitTokensDelta/prefillTokensDelta` 及命中率；H 系列给出 nonce 正确率与"是否通过 pctx_history 取得"，H02 给出 `lost evidence / known`（`oracle.quotedVerbatim===false` 的 episode 数，由 `parse-session.mjs verbatimQuote()` 离线从 episode 自己的 session JSONL 判定）；输出 `report.md` + `report.json` + 决策段（照 [协议](../testing/00-protocol.md) 的规则机械判定 `observe-only` / `limited-balanced-trial` / `inconclusive`，并按规则 6 逐 episode 判定 6.2 候选信号 `candidates`：`post-compaction-evidence-delta` / `inline-ref-marker` / `fold-time-model-hint`，无则 `none`）。
- `package.json`：`"eval:local": "node eval/local/run-matrix.mjs"`，`"eval:report": "node eval/local/report.mjs"`。
- `.gitignore`：`artifacts/local-eval/`、`eval/local/seeds/*.secret`。

import { expect, it } from "vitest";
import { summarize } from "../../eval/local/report.mjs";
import { assertArm } from "../../eval/local/arm-contract.mjs";

const req = (input: number | null, cacheRead: number | null) => ({ usage: { input, cacheRead, output: 10, cacheWrite: 0, totalTokens: (input ?? 0) + 10 }, stopReason: "stop", planId: null, replacementsApplied: 0, contextPercentBefore: null, at: "t", sessionId: "s", profile: "balanced" });

it("unknown usage is reported as unknown, never as zero, and pairs are grouped per case and arm", () => {
  const episodes = [
    { manifest: { caseId: "L01", arm: "native", rep: 1 }, status: "complete", oracle: { passed: true }, requests: [req(1000, 0), req(1200, 900)], mechanism: { folds: 0, replacements: 0, nativeCompactions: 0, historyReads: 0, historySearches: 0, verifiedReads: 0 }, engine: { prefixHitTokensDelta: 900, prefillTokensDelta: 1300, requestsDelta: 2, stableRestoresDelta: 1 }, wallMs: 30000 },
    { manifest: { caseId: "L01", arm: "balanced", rep: 1 }, status: "complete", oracle: { passed: true }, requests: [req(1000, 0), req(null, null)], mechanism: { folds: 0, replacements: 0, nativeCompactions: 0, historyReads: 0, historySearches: 0, verifiedReads: 0 }, engine: { prefixHitTokensDelta: null, prefillTokensDelta: null, requestsDelta: 2, stableRestoresDelta: 0 }, wallMs: 31000 },
  ];
  const s = summarize(episodes as never);
  const bal = s.byCaseArm["L01"]["balanced"];
  expect(bal.inputSum).toBe(1000);
  expect(bal.unknownUsage).toBe(1);
  expect(bal.engine.prefixHitRatio).toBeNull();
  expect(s.byCaseArm["L01"]["native"].engine.prefixHitRatio).toBeCloseTo(900 / 2200, 3);
});

it("an observe episode whose plugin resolved to a different profile is blocked", () => {
  const verdict = assertArm({ arm: "observe", configHash: "abc" }, { resolvedProfile: "balanced", configHash: "abc", hostVersion: "0.85.1" }, "/tmp/agentdir-with-extensions");
  expect(verdict.ok).toBe(false);
  expect(verdict.reason).toMatch(/profile/);
});

## 实施顺序

1. `arm-contract.mjs`、`report.mjs`（先纯函数 `summarize/decide`，后 CLI）。
2. `run-matrix.mjs`：manifest 冻结、顺序随机化（固定 seed 写入 manifest）、预算计数、断点续跑（`--resume <runDir>` 只补缺失 episode，不重跑已完成）。
3. `.gitignore`、`package.json` scripts；删除/标注旧运行器。
4. `--dry` 跑一遍打印顺序与预算（不调模型）。
5. **真实运行**：`pnpm eval:local -- --out artifacts/local-eval/$(date +%Y%m%d-%H%M%S)`；期间不要在 4090 上跑别的负载；总墙钟按 runbook。
6. `pnpm eval:report artifacts/local-eval/<runId>`，把 `report.md` 的决策段与关键表复制到 iterations 记录。

## 必测负例及边界

- 某 episode `status=blocked` → 不进统计，但计入 `blockedCount` 并在 report 顶部列出原因。
- native arm 的 `status.json` 意外存在 → blocked。
- `/v1/models` 中途变成 llama.cpp WORK（`n_ctx 200192`）→ 该 episode blocked，run 继续但 report 标 `engine-changed`。
- 同 case 两个 arm 的 `requests.length` 差异 > 3× → report 标 `trajectory-length-outlier`，不自动剔除。
- `engine.*` 差值为负（unit 重启计数归零）→ 置 null 并标 `engine-restarted`。
- `--resume` 不覆盖已存在 episode 目录。
