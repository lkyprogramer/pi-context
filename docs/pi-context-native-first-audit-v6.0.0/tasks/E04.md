## 交付接口

**Consumes**：E03 `report.md/report.json`、D01 `pnpm smoke`、`scripts/packed-host.mjs` 输出。

**Produces**：
- `docs/iterations/native-first-v6.md`：每个任务一段（任务、commit SHA 由 `git rev-parse` 读取、运行的命令与 exit、覆盖边界、剩余限制）；E03 段落粘贴决策与关键表；最后一段是本轮总决策与"下一轮只在什么证据出现时才做什么"。
- `README.md`：定位（observe+history 默认；balanced 阈值折叠，按决策标 `default-off, trial` 或 `default-off, not recommended`）；安装（`pi install npm:pi-context@file:<tarball>` 或 `-e dist/extension.js`）；`/pctx` 命令；不再提 capsule/pin/semantic/PCR。
- `docs/CONFIGURATION.md`：6.1 字段全表、默认值、trust、旧文件处理（A01 已写，此处核对与 report 一致）。
- `docs/OPERATIONS.md`：4090 隧道、`/pctx status` 读法、telemetry jsonl 位置与清理、如何回到 observe。
- `docs/release-v5.md`：顶部加"已被 6.1 取代"与指向 iterations 的链接；不改历史结论文本。
- `HANDOFF.md`：更新当前状态、下一步、已知限制；删除已失效的 v5 待办。
- `test/packed/install.test.ts`：安装最终 tarball 后 `pi list` 含 pi-context、`/pctx status` 输出 `hostVersion 0.85.1` 与 `resolvedProfile observe`；`uninstall` 后 session 文件仍在。

## 第一条行为 RED

```ts
import { readFileSync, existsSync } from "node:fs";
import { join } from "node:path";
import { expect, it } from "vitest";

const repo = join(import.meta.dirname, "../..");

it("docs describe only the 6.1 surface and the iterations log has a decision", () => {
  const readme = readFileSync(join(repo, "README.md"), "utf8");
  expect(readme).not.toMatch(/capsule|\bpin\b|semantic|PCR|pctx-v5\.json/i);
  expect(readme).toMatch(/schemaVersion.*6/);
  const iter = readFileSync(join(repo, "docs/iterations/native-first-v6.md"), "utf8");
  expect(iter).toMatch(/A01[\s\S]*E03/);
  expect(iter).toMatch(/decision:\s*(observe-only|limited-balanced-trial|inconclusive)/);
  expect(existsSync(join(repo, "docs/CONFIGURATION.md"))).toBe(true);
  expect(readFileSync(join(repo, "docs/CONFIGURATION.md"), "utf8")).toMatch(/triggerPercent/);
});
```

运行：

```bash
pnpm exec vitest run test/packed/install.test.ts --config vitest.config.ts
```

预期：README 仍描述 v5 的 capsule/pin，iterations 无决策行 → 断言失败。

## 实施顺序

1. 读 `report.json.decision`；若 `inconclusive`（blocked 过多或 engine-changed），先补跑缺失 episode（回 E03 `--resume`），不要在文档里补齐。
2. 写 iterations 总决策段：`decision: <值>`、证据行（配对通过率、折叠是否推迟压缩、cacheRead 曲线、墙钟）、限制（单模型、单机、样本量）。
3. README / CONFIGURATION / OPERATIONS / HANDOFF / release-v5 按上表修改。
4. `package.json version 6.1.0`；`pnpm build && node scripts/packed-host.mjs` 记录 tarball sha256 到 iterations。
5. `pnpm smoke`、`pnpm typecheck`、全仓 `pnpm exec vitest run --config vitest.config.ts`。

## 必测负例及边界

- `decision` 为 `limited-balanced-trial` 时 README 仍必须写 balanced 默认关闭与开启方法；不得把默认 profile 改成 balanced。
- `decision` 为 `observe-only` 时 CONFIGURATION 保留 `fold` 字段说明但标 `not recommended in this environment`，代码不删（下一轮证据可能不同）。
- HANDOFF 不含 4090 的 token/口令/内网路径以外的敏感信息；`192.168.10.29` 与端口可以出现（已在用户文档中）。
- release-v5 历史结论不改写。
