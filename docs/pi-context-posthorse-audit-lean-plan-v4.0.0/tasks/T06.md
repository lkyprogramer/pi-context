## 第一个RED

在上述指定测试文件中加入以下具体回归（已有同名文件就在现有describe下增加）。遇到新目标模块不存在的编译失败，应继续实现接口后确认测试能够针对目标行为变红；不能只保存MODULE_NOT_FOUND就称行为缺陷已复现。

```ts
import { expect, it } from "vitest";
import { sliceUtf8Page } from "../../core/src/retrieval/bounded.js";
it("rejects mid-codepoint offsets and preserves complete UTF8 pages",()=>{
 const bytes=Buffer.from("A中🙂Z","utf8");
 expect(()=>sliceUtf8Page({bytes,byteOffset:2,maxBytes:8})).toThrow("INVALID_BYTE_OFFSET");
 const page=sliceUtf8Page({bytes,byteOffset:1,maxBytes:7});
 expect(Buffer.from(page.bytes).toString("utf8")).toBe("中🙂");
 expect(page.nextByteOffset).toBe(8);
});
```

## 实施步骤

1. 先核对现read/recall真实实现路径；现源码在commands子目录时仅修改对应两文件，记录索引，不复制工具。

2. 将上面byte oracle接真实工具：offset2应明确错误，不得返回替换字符；连续页面重组与原文相等；header/footer计入预算。

3. 无Recall需求时不查FTS、不输出空directory/lease；避免保存每个请求不同head造成无效新session。

4. FTS cache按Evidence索引版本失效，而不是usage/lease写导致全部total_changes失效；权限变化仍强制失效。

5. 用有真实usage/lease写的100轮追加测试测查询次数/Owner数，先修正确性再谈P95；全文解密仍如实声明。
