## 实施步骤

1. 新增resolveRuntimeMode并将默认设ingress；报告publicationClaim字段绝不当功能开关。

2. ingress注册安全观察/read工具但context返回原消息且compact不接管；off不注册修改hook；全runtime明确启用。

3. full-state只有已有grounded goal/error/next-action才渲染，不从assistant自述构造已完成；hash/head详细信息移至details/receipt。

4. 检查源中有未消费batch或未解决错误时capsule是否保留关键内容；不能只用directive非空作为质量底线。

5. 选择Native fallback不修改已持久原日志；目标窗口不足优先保留必需尾部，必要时明确报错。
