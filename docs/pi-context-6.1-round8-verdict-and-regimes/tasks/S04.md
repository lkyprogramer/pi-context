## 接口合同

**Consumes：** `run-matrix.mjs:212-216` 已有的 `spec.evidence.kind === "verbatim-quote"` 分支（对 H02 生效）；`parseSession(sessionFile).entries`；S03 的 `plan.exactQuoteIds`。

**Produces：**

- `parse-session.mjs`：`verbatimQuote(parsed, { linePattern, sinceMs, sourceKind = "isError" })`；`sourceKind:"any"` 时源行取分支上首个匹配 `linePattern` 的 toolResult 文本行（不限 isError）。
- `cases.json` Q05：`evidence: { kind:"verbatim-quote", sourceKind:"any", linePattern:"idempotency broken: reservation ZX-731 replayed after callback\\." }`。`review-fixtures/Q05.json` 保留 `contains` 文件 oracle，另加 `"exactQuote": true`。
- `gate.mjs`：`pairsFromItt` 用 `plan.exactQuoteIds`（S03 已引入）填 `nativeQuote/candidateQuote`；删除硬编码 `"H02"`。`capabilitiesFromItt` 同理。
- `report.mjs`：`candidates(summary, episodes, plan)` 按 §4 四条规则；每条输出 `{candidate, evidence[], status:"met"|"below-gate"}`；CLI 把结果写进 `decision.candidates`（不再传空数组）。
- `run-matrix.mjs`：manifest 增加 `distDigest`；live 模式 dirty 拒绝 / `--allow-dirty` → `manifest.diagnosticOnly = true`。
- `report.mjs`：报告头 `dist <distDigest12> (entry <pluginSha256 12>)`；`diagnosticOnly` 时 decision 强制 `inconclusive`，reason `dirty-tree diagnostic run (<dirtyDigest12>)`，头部加粗 `DIAGNOSTIC ONLY`；尾注改为 `Small samples (${plan.repsPerCase} reps per cell). Counts only; no percentages extrapolated.`。
- `bundle.mjs`：bundle 携带 `distDigest`、`diagnosticOnly`、candidates；`recomputeDecision` 同样强制 `inconclusive`。

## 最小实施顺序

1. `parse-session.mjs` `sourceKind`；单测：同一 session 上 `isError` 与 `any` 分别取到不同源行。
2. `cases.json` Q05 `evidence`；`local-cases.test.ts` 增加断言 `Q05.evidence.sourceKind === "any"`。
3. `gate.mjs` 用 `plan.exactQuoteIds`；`report.mjs` `candidates(summary, episodes, plan)` 与 CLI 接线。
4. `run-matrix.mjs`：`distDigest`（`sha256(JSON.stringify(Object.entries(distFiles).sort()))`）；live 模式 `porcelain.length > 0 && !args["allow-dirty"]` → `die("live run refused: working tree dirty; use --allow-dirty for a diagnostic-only run")`；带标志写 `diagnosticOnly:true`。

## 负例与边界

- `sourceKind:"any"` 但源行只出现在 assistant 文本中（模型自己编的）→ 不算源，返回 null。
- 引用与源行只差标点（如缺句号）→ `false`。
- `linePattern` 匹配到多行 → 取分支顺序首行。
- `--allow-dirty` 的 run 不能写入 `review-final/`（S07 的脚本拒绝 `diagnosticOnly:true` 的 bundle）。
- `distDigest` 必须对 `distFiles` 的键排序后计算，键顺序变化不改变摘要。
