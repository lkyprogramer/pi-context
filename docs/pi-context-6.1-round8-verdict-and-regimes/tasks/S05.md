## 接口合同

**Consumes：** `startCredentialBroker({ socketPath, socketMode, allowedToken, allowedModel, targetBaseUrl, apiKey, maxRequests, maxBodyBytes, requestTimeoutMs })`（Linux 路径已用）；容器内 `eval/sandbox/unix-relay.mjs`（HTTP 127.0.0.1:8080 → `PCR_BROKER_SOCK`）。

**Produces：**

- `broker-unix.mjs`：从 **stdin 第一行** 读取 upstream key（不读文件、不读 env），调用 `startCredentialBroker({ socketPath: process.env.PCTX_BROKER_SOCKET_PATH ?? "/run/pctx/broker.sock", socketMode: 0o660, ... })`；就绪后向 stdout 打印一行 `{"ready":true,"socketPath":...}`；stdin 关闭不退出；SIGTERM 时关闭并删除 socket 文件。
- `run-episode.mjs`（Darwin 分支）：
  1. `docker volume create pctx-sock-<rand>`；
  2. `docker run --rm --user 0 -v <vol>:/run/pctx <image> chown 1000:1000 /run/pctx`；
  3. `spawn("docker", ["run","-i","--rm","--name",<name>,"--read-only","--tmpfs","/tmp:rw,size=64m","--user","1000:1000","--cap-drop","ALL","--security-opt","no-new-privileges","--memory","512m","--pids-limit","64","-v",<vol>+":/run/pctx","-v",<repo>/scripts/credential-broker.mjs:/opt/pctx/credential-broker.mjs:ro,"-v",<here>/sandbox/broker-unix.mjs:/opt/pctx/broker-unix.mjs:ro,"-e",PCR_LIVE_BASE_URL,"-e",PCR_LIVE_MODEL,"-e",PCTX_BROKER_TOKEN,"-e",PCTX_BUDGET_MODEL,<image>,"node","/opt/pctx/broker-unix.mjs"])`，向 stdin 写 `${apiKey}\n`，等待 stdout `ready` 行（≤5s）；
  4. 就绪探针：`docker exec <cid> node -e "require('http').request({socketPath:'/run/pctx/broker.sock',path:'/v1/models'},r=>process.exit(r.statusCode===403?0:1)).on('error',()=>process.exit(2)).end()"`；
  5. 传给 `run-agent.sh` 的 env：`PCTX_BROKER_VOLUME=<vol>`（不再传 `PCTX_BROKER_CID`）；
  6. 结束：`docker rm -f <cid>`、`docker volume rm <vol>`；
  7. `broker-hop.json = { kind:"darwin-sidecar-volume-network-none", volume, sidecar, socketPath:"/run/pctx/broker.sock", agentNetwork:"none" }`。
  删除 `startBrokerSidecar` 中 `mkdtempSync(join("/tmp","pctx-k-"))` 与 `writeFileSync(...upstream.key...)`。
- `run-agent.sh`：只保留一种 `docker run`：`--network none`，socket 挂载二选一——`-v "$PCTX_BROKER_VOLUME:/run/pctx"`（Darwin）或 `-v "$SOCK_DIR:/run/pctx"`（Linux bind）；`-e PCR_BROKER_SOCK=/run/pctx/broker.sock`。删除 `BROKER_CID` 分支。两者都缺 → `exit 3`。
- `secure-preflight.mjs --canary`：增加 `agentEgress`：以与 agent 相同的参数（`--network none`、只读、1000:1000）启动镜像执行 `fetch("http://1.1.1.1/", {signal: AbortSignal.timeout(3000)})`，必须失败；输出 `{ok, env, models, proc, agentEgress:false, canary:<sha12>}`；`agentEgress:true` → exit 1。
- `credential-broker.mjs`：若 `socketPath` 目录不可写，抛出含路径的错误（不静默回退到 TCP）。

## 非目标

不改 Linux 路径行为；不给 agent 任何网络；不把 Key 写入 env、文件、manifest、日志；不改 grader 容器（保持 `--network none`、无 socket）。

## 负例与边界

- volume 不存在或 chown 失败 → `blocked`，不回退到 netns 或 host。
- sidecar 5s 内未 `ready` → `docker rm -f` + `volume rm` + `blocked`。
- stdin 写入失败（sidecar 已退出）→ `blocked`，且不在错误信息里回显 key。
- `PCTX_BROKER_VOLUME` 与 `PCTX_BROKER_SOCK` 同时存在 → 优先 volume，并在 `broker-hop.json` 记录。
- 任意异常路径都不得在 `<episode>/` 目录留下含 key 的文件；测试用随机 canary 字符串代替真实 key（`secure-preflight` 已如此）。
