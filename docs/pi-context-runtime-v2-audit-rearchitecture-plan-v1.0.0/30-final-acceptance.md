# 最终验收

产品只能在以下证据同时存在时称为 deterministic MVP：

- 当前 commit required CI 全绿；
- clean npm pack + clean Pi install；
- 真实 tool_result → CAS → reducer → exact read vertical path；
- 真实 user input → directive clause → checkpoint；
- context materializer 使用实际 model limits；
- compaction reject 可回退 Native；
- restart/branch recovery；
- W1 locked Gate 通过；
- W2 hard + quality Gate 通过，或明确保留 Pi Native；
- release artifact 含 immutable run bundle。

Semantic Beta 必须额外通过 proposer/verifier mutation tests、background fencing 和 B2 closed-loop Gate。
