# A01 — 移除所有硬编码临时目录

## 元数据

- Wave：`W0`
- Depends on：A00
- Findings：F101, F102
- Owner：由 `taskctl claim` 分配
- Completion：必须同时有 RED、GREEN、FULL-GATE、Evidence Seal、Commit SHA

## 目标

所有测试临时目录使用 `mkdtempSync(join(tmpdir(), ...))` 或 test context 注入。

## 允许修改

- `tests/**`
- `packages/*/test/**`

禁止修改未列出的生产文件；若发现依赖缺口，写 Blocker，不得扩大 Scope。

## 实施步骤

1. 搜索 `/var/folders/`、`/Users/`、开发机绝对路径
2. 建立 testkit `createTempWorkspace()`
3. 在 afterEach 做 scope-local cleanup

## 必须先写的 RED 测试

- Linux/macOS path portability
- parallel workers no collision
- cleanup after failure

RED 必须因目标缺陷失败，而不是 import/path/fixture 错误。

## 命令

```bash
pnpm test:unit
pnpm test:integration
```

## 负例与故障要求

- scope/model/branch 不匹配必须 typed fail；
- AbortSignal 必须在 I/O/模型边界生效；
- 不得通过 hardcode 指标或 snapshot 常量过 Gate；
- 不得修改 locked corpus 同一 major 来修复实现失败；
- 所有临时目录使用 OS temp fixture。

## 验收

仓库测试源码不含开发机临时路径，Ubuntu/macOS 对应失败归零。
