# A04 — 拆分 Unit/Integration/Live/Pack 测试 Lane

## 元数据

- Wave：`W0`
- Depends on：A01, A02, A03
- Findings：F101, F102, F103
- Owner：由 `taskctl claim` 分配
- Completion：必须同时有 RED、GREEN、FULL-GATE、Evidence Seal、Commit SHA

## 目标

默认 unit 不运行 provider/live/pack；各 lane 有明确条件与超时。

## 允许修改

- `vitest*.ts`
- `package.json`
- `.github/workflows/**`

禁止修改未列出的生产文件；若发现依赖缺口，写 Blocker，不得扩大 Scope。

## 实施步骤

1. 新增 vitest.unit/integration/acceptance/live config
2. 重命名伪 live 测试为 integration
3. CI 分步产出独立 artifact

## 必须先写的 RED 测试

- selection tests verify no overlap
- live requires env
- pack lane isolated

RED 必须因目标缺陷失败，而不是 import/path/fixture 错误。

## 命令

```bash
pnpm test:unit
pnpm test:integration
pnpm test:acceptance
```

## 负例与故障要求

- scope/model/branch 不匹配必须 typed fail；
- AbortSignal 必须在 I/O/模型边界生效；
- 不得通过 hardcode 指标或 snapshot 常量过 Gate；
- 不得修改 locked corpus 同一 major 来修复实现失败；
- 所有临时目录使用 OS temp fixture。

## 验收

每个 lane 可独立复现，失败不会被混成一个 unit log。
