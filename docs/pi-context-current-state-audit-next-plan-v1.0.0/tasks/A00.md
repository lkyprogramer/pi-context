# A00 — 冻结当前证据与审计基线

## 元数据

- Wave：`W0`
- Depends on：无
- Findings：F101, F130
- Owner：由 `taskctl claim` 分配
- Completion：必须同时有 RED、GREEN、FULL-GATE、Evidence Seal、Commit SHA

## 目标

把 HEAD、report snapshot、CI run/artifacts、source tree hash 固定为不可变输入。

## 允许修改

- `audit/current/**`
- `artifacts/audit/**`

禁止修改未列出的生产文件；若发现依赖缺口，写 Blocker，不得扩大 Scope。

## 实施步骤

1. 生成 current-baseline.json，记录 HEAD/tree/report commit/CI run
2. 保存 Ubuntu/macOS unit failure summary 与 SHA-256
3. 验证工作树 clean，任何后续实验写入新 runId

## 必须先写的 RED 测试

- baseline hash two-run equal
- dirty tree must fail

RED 必须因目标缺陷失败，而不是 import/path/fixture 错误。

## 命令

```bash
node scripts/audit/freeze-current.mjs
node scripts/audit/verify-current.mjs
```

## 负例与故障要求

- scope/model/branch 不匹配必须 typed fail；
- AbortSignal 必须在 I/O/模型边界生效；
- 不得通过 hardcode 指标或 snapshot 常量过 Gate；
- 不得修改 locked corpus 同一 major 来修复实现失败；
- 所有临时目录使用 OS temp fixture。

## 验收

同一 commit 的 baseline 两次完全相等，且 CI artifact hash 可验证。
