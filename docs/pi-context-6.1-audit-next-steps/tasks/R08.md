# R08 · 重建轻量试用判定和不可变run包

依赖：R07, R06。本任务实现前读取[目标设计](../design/00-target.md)及[执行协议](../AI-START-HERE.md)。

## 文件范围

- `eval/local/gate.mjs`
- `eval/local/report.mjs`
- `eval/local/run-matrix.mjs`
- `eval/local/bundle.mjs`
- `test/unit/trial-gate.test.ts`
- `test/integration/run-bundle.test.ts`

## 接口合同

**Consumes：** R07全attempt计量，冻结plan/manifest；R06父进程日志和沙箱结果。

**Produces：** `evaluateTrial({pairs,capabilities,objective})`；pair含nativePassed,candidatePassed,foldRequired,foldApplied,criticalViolation,evidencePassed；objective含metric、known、relativeChange、minImprovement。机器decision不由报告散文覆盖。

上述新增函数/文件为本任务必须实现的API，不是当前仓库已经存在的能力。共用Fixture代码见[review-fixture.ts](../testing/review-fixture.ts)。

## 非目标

不重建旧PCR包，不更换宿主或模型，不调60%/40%/minRemoved/recent4默认参数，不加语义后台，不通过修改Oracle让失败变成功。未经安全预检不运行真Provider。

## TDD第一条红测

将以下测试写入文件清单中的对应test文件，合并而非覆盖已有测试：

```ts
import { expect, test } from "vitest";
 import { evaluateTrial } from "../../eval/local/gate.mjs";
 test("one loss per two repetitions is not a passing quality gate", () => {
   const pairs=Array.from({length:12},(_,i)=>({caseId:"q"+Math.floor(i/2),rep:i%2,
     nativePassed:true,candidatePassed:i%2===0,foldRequired:true,foldApplied:true,
     criticalViolation:false,evidencePassed:true}));
   const d=evaluateTrial({pairs,capabilities:[],objective:{metric:"logical-input",known:true,relativeChange:0.4,minImprovement:0.1}});
   expect(d.decision).not.toBe("limited-balanced-trial");
 });
```

运行：

```bash
pnpm exec vitest run test/unit/trial-gate.test.ts test/integration/run-bundle.test.ts --config vitest.config.ts
```

新API未建立时的导入失败只是起始红测；实现最小API后必须确认断言在错误行为上失败，不能只保留“模块不存在”的红测记录。

## 最小实施顺序

1. 判定优先安全/完整性→机制达成→关键质量→普通新增失败→预登记收益。无fold质量不得入通过分母；H02 quote是明确必需断言，不再只是候选建议。
2. 普通候选新增失败标review-needed，关键违规blocked；样本全过但cost未知标quality-qualified-cost-unknown，不能自动升级。主目标与阈值在run开始冻结，不能运行后换指标。
3. report只读run内plan/config/oracle版本和attempt ledger，不读当前repo cases。预先计划的missing输出NOT_RUN，ITT保留全部。偶数median和cluster paired差使用R07。
4. manifest绑定全部dist文件摘要、tarballHash、安装Pi版本与包hash、模型/参数、配置、源commit、dirty差异digest、场景hash和顺序；不只entry.js。
5. 生成脱敏bundle，只有必要的id/Hash/数值/oracle结果，raw private session本地分开。不在库里提交大量模型思考和真实Key。
6. 增加旧Gate的质量减半、H02quote失败、机制0、未知成本、missingpair反例；保持失败后的report可生成但exit/decision明确区分。

## 负例与边界

- 0个恢复机会不能成功；候选全部notrun不能全过。
- 改一字scenario或插件依赖模块导致manifest校验失败。
- summary自然语言不能覆盖结构化oracle=false。
- retry-policy与first-attempt成功率分别输出。
