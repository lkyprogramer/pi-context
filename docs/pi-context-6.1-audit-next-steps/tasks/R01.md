# R01 · 用当前单插件命令替换失效CI

依赖：无。本任务实现前读取[目标设计](../design/00-target.md)及[执行协议](../AI-START-HERE.md)。

## 文件范围

- `package.json`
- `.github/workflows/required.yml`
- `.github/workflows/compatibility.yml`
- `test/unit/ci-contract.test.ts`
- `docs/iterations/next-fixes.md`

## 接口合同

**Consumes：** 现有typecheck/build/test/compat:scan/smoke；现有packed smoke已在远端通过。

**Produces：** `pnpm check` = typecheck + test + compat:scan；CI只调用存在的check/build/smoke，不执行Provider模型任务。

上述新增函数/文件为本任务必须实现的API，不是当前仓库已经存在的能力。共用Fixture代码见[review-fixture.ts](../testing/review-fixture.ts)。

## 非目标

不重建旧PCR包，不更换宿主或模型，不调60%/40%/minRemoved/recent4默认参数，不加语义后台，不通过修改Oracle让失败变成功。未经安全预检不运行真Provider。

## TDD第一条红测

将以下测试写入文件清单中的对应test文件，合并而非覆盖已有测试：

```ts
import { readFileSync } from "node:fs";
 import { expect, test } from "vitest";
 test("CI uses current single-plugin commands only", () => {
   const pkg = JSON.parse(readFileSync("package.json", "utf8"));
   const ci = readFileSync(".github/workflows/required.yml", "utf8");
   expect(typeof pkg.scripts.check).toBe("string");
   expect(ci).not.toContain("scripts/ci/compile-runtime.mjs");
   expect(ci).not.toContain("tests/w1-gate");
   expect(ci).not.toContain("test:unit");
 });
```

运行：

```bash
pnpm exec vitest run test/unit/ci-contract.test.ts --config vitest.config.ts
```

新API未建立时的导入失败只是起始红测；实现最小API后必须确认断言在错误行为上失败，不能只保留“模块不存在”的红测记录。

## 最小实施顺序

1. 增加check脚本，保留现有test/include= test/**/*.test.ts；不要把归档tests重新加回。
2. required设一个check job(Node22.19.0、pnpm10.15、frozen install)，一个stock-smoke job(pnpm build && pnpm smoke)。失败exit向外传播，报告不作为质量通过。
3. compatibility改为可手动运行的单个额外受支持Node版本；无额外平台需要时合并进required。清理引用已删除文件的shell命令，不以创建空脚本满足旧CI。
4. 检查当前vitest exclude三份旧文件，记录其是历史归档或迁移到活动测试；本轮新增R07/R08测试必须被默认include命中。

## 负例与边界

- 随机去掉check或向workflow加入旧路径，契约测试应失败。
- 无网络Provider凭据下check不得尝试Live。
- 冻结安装/类型/打包通过与benchmark未运行分开报告。
