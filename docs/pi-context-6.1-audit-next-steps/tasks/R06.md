## 最小实施顺序

1. 只在父Broker读取真实.env；固定target/model/path；Agent models.json仅含一次run内有效的opaque broker令牌，不含上游Key。限制请求数/bytes/耗时并在run结束撤销。
2. Agent --network none，通过仅broker服务可读写的Unix socket relay联系父代理。grader --network none且没有socket。H03走同一沙箱，删除宿主直跑路径。
3. 真实运行从最终tarball展开，只读挂载plugin；Agent只写work/tmp，不可改manifest/parent usage logs/oracle结果。父进程采集并拥有权威计量。
4. secure-preflight用随机假上游Key，模型替身在Agent中尝试read常见配置、env、/proc和出站；报告只有布尔值/Hash，不打印canary；真实Key永远不用于泄漏断言。
5. grader对baseline与candidate路径并集检测未授权删除/改写/新增，拒绝symlink；固定.class忽略和可信POM/Oracle，不能运行后修改忽略表。
6. 模拟broker超时/取消/大响应，资源按限额关闭；沙箱不可用就BLOCKED，不fallback host。

## 负例与边界

- Agent尝试读models.json只能得到本地临时令牌。
- broker拒绝代理任意URL、其他model与/metrics路径；metrics由父进程单独读取。
- Candidate删除protected文件或替为symlink应判失败。
