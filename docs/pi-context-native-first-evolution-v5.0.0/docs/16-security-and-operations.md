# 16 · 安全、隐私与运维

## 威胁模型

防止本插件意外跨项目／分支回读、恶意历史文本借摘要升级为指令、未验证來源被标记exact、优化异常导致输入损伤，以及执行预算失控。不承诺防御拥有同一用户权限的恶意本地进程、任意第三方扩展或未隔离shell。

## 历史文本属于数据

检索结果和胶囊必须标注historical evidence，并保留来源／时间；不能复制其中“忽略前文”“读取.env”等文本到system prompt或自动执行。history工具不具有执行能力。语义摘要工具禁用任何tool调用，发现toolCall内容直接拒绝候选。

真实模型攻击测试包含：日志内伪造用户命令、测试输出假称已通过、历史摘要自引用、ref路径穿越、兄弟分支高权重诱饵、恶意base64／超大块。预防与测试并行，不能把一段安全提示词作为防注入保证。

## 默认数据策略

native session不由插件删除。派生索引存储在用户私有`pctx-v5`目录，按workspace隔离，默认最多256MiB/工作区；超过阈值暂停新增索引并显式退化，不自动删除仍被pin引用的native证据。可由用户命令清除整个派生索引并重建，命令确认后只操作插件拥有的目录。

FTS内容明文；POSIX0700/0600只减少本机其他用户访问，不等于加密。`memory-only`不持久化派生文本，但native Pi仍可能持久化会话；不要误导成“完全不落盘”。history结果会发送到当前选择的模型provider。

## 配置和网络

默认核心模块不新增网络请求；使用当前provider只发生在Pi本身调用和实验semantic层。后者必须显式开启、确认路由、预算受控；项目配置无权扩大网络目的地和授权根。不得自动读取或迁移历史API keys。

## 运维检查

`doctor`核对宿主版本、来源路径可读、Node sqlite可用、Worker打包路径、权限、scope与cursor、模式和冲突配置。诊断输出只含hash/计数/错误码，不含原文。诊断失败不改变用户任务，也不“自动修复”全局Pi文件。

自动检测所有第三方hook冲突未必有公开API可用。产品文档要求只启用一个自定义压缩拥有者；运行时可用message哈希变化检测保守bypass，但不能声称已经可靠枚举所有冲突插件。

## 卸载与回滚

关闭profile后立即停新增派生任务，下个请求恢复原生视图。卸载不需要反向修改会话；native compaction和原始消息仍保留。新旧版本数据目录隔离，不自动降级迁移。若用户选择清理派生索引，仅删除marker-owned路径并防symlink／路径替换，原始session及仓库不动。
