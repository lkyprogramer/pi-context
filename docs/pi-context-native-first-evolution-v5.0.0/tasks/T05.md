## RED：先写可失败的行为测试

同一文本块可分页重组；共享对象不误判循环；来源变化能使旧ref失效。

1. ASCII/中文/emoji/CRLF分页重组逐字节相同。
2. 非循环共享引用可正常hash，真实循环返回明确错误。
3. 伪造路径、负数offset、越界或切断UTF-8字符拒绝或校正为明确有效边界。

先确认测试因目标行为尚未实现而失败，而不是文件拼错、测试没有被发现或依赖缺失。基础模块缺失时先放最小可编译接口，再观察断言RED，不把import错误当功能测试证据。
