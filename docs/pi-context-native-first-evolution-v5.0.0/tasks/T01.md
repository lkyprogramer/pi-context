## RED：先写可失败的行为测试

在未修改官方Pi 0.85.1中以最小扩展加载并注册一个无副作用命令；不得提供PCR自定义导出。

1. 扫描产物及锁文件，存在patchedDependencies或PCR_INGRESS_METADATA_CONTRACT即失败。
2. 以官方实际resource loader加载打包入口；不能用host stub代替。
3. 记录Node、Pi package/source hash，npm发布包身份与源码不一致时阻断。

先确认测试因目标行为尚未实现而失败，而不是文件拼错、测试没有被发现或依赖缺失。基础模块缺失时先放最小可编译接口，再观察断言RED，不把import错误当功能测试证据。

## GREEN：最小实施步骤

1. 建立private:true的单包构建，保留旧实现不删除。
2. 只使用公开包导出并固定peer；生成锁文件后执行干净安装。
3. 构建最小tarball，使用临时HOME/agentDir加载和卸载；检查依赖树没有多装第二份Pi、loader解析的是目标宿主，保存实际CLI help与日志。

完成后删除本任务内部重复状态和冗余转发，不增加不在任务范围内的策略。修改契约需要同步更新受影响任务与测试，不能用类型断言绕过。
