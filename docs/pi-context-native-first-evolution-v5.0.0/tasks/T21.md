## RED：先写可失败的行为测试

Agent不能读grader/host home/生产密钥；模型请求只能经预算化代理。

1. network none、非root、只读rootfs、cap-drop、pids/memory limits实际生效。
2. 代理拒绝任意URL/CONNECT/文件接口，凭据不出宿主代理。
3. 隔离探针失败时任务状态blocked，工具不会执行。

先确认测试因目标行为尚未实现而失败，而不是文件拼错、测试没有被发现或依赖缺失。基础模块缺失时先放最小可编译接口，再观察断言RED，不把import错误当功能测试证据。
