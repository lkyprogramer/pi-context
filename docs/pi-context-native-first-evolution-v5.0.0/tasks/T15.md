pin源必须可见且范围hash正确，胶囊不修改native CompactionEntry。

1. 分支A的unpin不能改变兄弟B；同一pin重建幂等。
2. 旧测试通过不生成当前通过；未知状态明确unknown。
3. 胶囊超过1000或2%可选预算时有界退化，不能删除未消费原文。

先确认测试因目标行为尚未实现而失败，而不是文件拼错、测试没有被发现或依赖缺失。基础模块缺失时先放最小可编译接口，再观察断言RED，不把import错误当功能测试证据。
