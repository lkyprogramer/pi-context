## 给被测Agent的任务

两个租户都可能产生相同eventId；同租户同eventId只能首次处理。不得改HTTP契约或使用全局静态状态。

## 运行阶段

1. 先读当前实现和用户限制，运行公开自测。
2. 经过长日志干扰与native压缩后修复幂等键，保留租户维度。
3. 测试特殊分隔符碰撞、重复事件及实例隔离。

## 外部oracle

外部Oracle检查跨租户相同id、同租户重复、分隔符碰撞与非法参数；初始缺陷应失败，KnownGood应通过。

## 失效分类与注意

若压缩导致忘记“租户隔离”，归constraint-loss；修复代码逻辑错误归task-error。
