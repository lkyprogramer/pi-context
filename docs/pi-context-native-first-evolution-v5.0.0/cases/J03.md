# J03 · Spring事务self-invocation与回滚

材料状态：`planned-spring`。全部是设计／合成素材，不冒充独立真实业务样本。

## 给被测Agent的任务

同类内部调用@Transactional方法，异常时部分写入未回滚。要求保持公开方法签名，不能把异常吞掉。

## 运行阶段

1. 准备Spring服务、内存测试DB及真实事务测试。
2. Agent读取堆栈、代理与调用链，经历压缩后修复边界。
3. 重复运行异常／成功分支，验证两张表原子性。

## 外部oracle

独立集成测试验证失败时两表均无新增，成功时两表都有记录；检查入口签名保持、未关闭事务或忽略异常。

## 失效分类与注意

本包提供设计，不包含已运行Spring镜像；T21/T23负责实现，未实现记not-run。

本场景B0/B2使用相同初始源码、约束与预算，独立sandbox运行，允许中间轨迹不同。任务seed和恢复nonce在冻结规则下生成。grader目录、已知正确实现和期望输出不挂载给Agent；只有用户拥有完整测试资料。

实际结果必须包含编译／测试命令、退出码、差分、原生session、回读证据、所有provider usage与wall time。当前未运行的live／Spring环节填NOT-RUN，不从Java小fixture通过外推。
