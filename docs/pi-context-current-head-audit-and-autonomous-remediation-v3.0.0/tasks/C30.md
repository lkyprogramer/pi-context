## Goal

生成去敏、可复算且不污染 Git 的 RC Bundle，并形成可复算 Evidence v3。

## Allowed Files

- `scripts/release/build-run-bundle.mjs`
- `scripts/release/secret-scan.mjs`

- `.github/workflows/publication.yml`
